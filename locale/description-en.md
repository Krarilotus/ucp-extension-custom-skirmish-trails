# Custom Skirmish Trails

This extension enables custom skirmish trails, specified in .csv files.

## Possibilities
You can download the first trail [here](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/resources/trails/template-First-Edition-Trail.csv), the warchest [here](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/resources/trails/template-Warchest-Trail.csv) and the extreme trail [here](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/resources/trails/template-Extreme-Trail.csv).

An easy online editor can be found here: https://edit-csv.net/

## Trail settings, mission files and languages

Each trail can have a trail settings file, set in the GUI, with its title, summary, starting
year, pictures, mission positions, AI names, mission data and language files. Missions can also
be kept as one JSON file each, and every language as a small JSON file with only its texts.
Optional csv columns set mission-specific player names and the human player's lord. The formats
are described in [docs/trail-files.md](https://github.com/gynt/ucp-extension-custom-skirmish-trails/blob/main/docs/trail-files.md).
