# Custom Skirmish Trails

Cette extension permet des parcours d’escarmouche personnalisés, définis dans des fichiers `.csv`.

## Possibilités

L’archive ZIP contient un modèle `template.csv` décrivant les champs modifiables. Vous pouvez aussi télécharger les modèles des trois parcours :

- [Premier parcours](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/template-First-Edition-Trail.csv)
- [Parcours Warchest](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/template-Warchest-Trail.csv)
- [Parcours Extreme](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/template-Extreme-Trail.csv)

Un éditeur en ligne simple : [edit-csv.net](https://edit-csv.net/)

- `trade_`: Utilisez par exemple `trade_spear` (au singulier !) pour activer ou désactiver le commerce de cette marchandise.
