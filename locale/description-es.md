# Custom Skirmish Trails

Esta extensión permite campañas de escaramuzas personalizadas, definidas mediante archivos `.csv`.

## Posibilidades

El ZIP contiene una plantilla `template.csv` que describe los campos modificables. También puedes descargar las plantillas de las tres campañas:

- [Primera campaña](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/template-First-Edition-Trail.csv)
- [Campaña Warchest](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/template-Warchest-Trail.csv)
- [Campaña Extreme](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/template-Extreme-Trail.csv)

Editor en línea sencillo: [edit-csv.net](https://edit-csv.net/)

- `text_dexcription_line_01 - 08`: Usa `""` para escribir el texto que aparece en el menú de inicio de la misión de escaramuza.
- `trade_`: Por ejemplo, utiliza `trade_spear` (¡en singular!) para activar o desactivar el comercio de ese producto.
