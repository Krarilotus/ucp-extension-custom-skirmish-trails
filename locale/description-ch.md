# Custom Skirmish Trails

此扩展支持由 `.csv` 文件定义的自定义遭遇战征途。

## 可修改内容

扩展 ZIP 包中的 `template.csv` 模板说明了可修改的字段。也可以单独下载三条征途的模板：

- [第一条征途](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/template-First-Edition-Trail.csv)
- [Warchest 征途](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/template-Warchest-Trail.csv)
- [Extreme 征途](https://raw.githubusercontent.com/gynt/ucp-extension-custom-skirmish-trails/refs/heads/main/template-Extreme-Trail.csv)

简便的在线编辑器： [edit-csv.net](https://edit-csv.net/)

- `trade_`: 例如使用 `trade_spear`（单数形式！）来开启或关闭该商品的交易。
